### 🔒 [Concurrency-Safe Reservation Engine, Backend](https://github.com/Malik-AK47/reservation_engine) *(in progress)*

A reservation backend designed so that two users can never successfully claim the same resource, even under concurrent requests and client retries.

- ✅ Requirements, architecture and data model designed (modular monolith, PostgreSQL as the source of truth)
- ✅ Flyway-managed schema with a partial unique index that allows at most one active reservation per resource
- 🚧 Authentication, entity mappings and error handling
- 📋 Pessimistic locking, idempotent hold creation, expiry handling and concurrency tests against real PostgreSQL

`Java` `Spring Boot` `Spring Security` `JWT` `JPA/Hibernate` `PostgreSQL` `Flyway` `Docker Compose` `JUnit` `Mockito` `Maven`
